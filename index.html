Starting point

Build on what is
already working.

Rather than adding duplicate sections, these suggestions focus on keeping existing content fresh and making it more valuable to students.

What the website already has

The current site includes an introduction to GDG@DSU, event highlights, a photo gallery, a Discord community link, partners, and navigation to key pages.

AboutEventsGalleryDiscordPartners

Where I would focus next

Improve the freshness and visibility of information, highlight learning in progress, and make the experience smoother on smaller screens.

Fresh contentDiscoverabilityPractical valueMobile UX
The suggestions

Four areas worth
improving.

Small, realistic changes that could make the existing website more useful without changing its overall identity.

01 / CONTENT

Keep events updated

Update the events section more frequently so visitors can quickly see what's coming up and what the community has been doing recently.

Suggested change: clearer dates, status, and latest activity.
02 / VISIBILITY

Highlight smaller sessions

Give short programming meetups, technical discussions, and focused workshops more visibility alongside larger events.

Suggested change: make smaller sessions easy to discover.
03 / COMMUNITY

Show what members are learning

Alongside event photos, share practical outcomes: projects, demos, takeaways, or short recaps created by members.

Suggested change: more learning-in-action content.
04 / EXPERIENCE

Improve navigation on mobile

Make key information easier to reach on phones, with a cleaner navigation flow and readable event details across screen sizes.

Suggested change: simpler mobile browsing and clearer page hierarchy.
The overall idea

Less about adding more pages. More about making the existing ones useful.

A website should reflect what's happening in its community. Keeping it current and showing the practical value of being involved can make it a better first stop for students.
